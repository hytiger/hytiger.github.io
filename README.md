# hytiger.github.io

GitHub Pages user site, used as the **developer website** for BaroFX on Google Play.

- `app-ads.txt` — AdMob authorized sellers file. Must stay at the site root:
  https://hytiger.github.io/app-ads.txt
- `index.html` — small landing page (Play link, privacy policy).
- `.nojekyll` — serve files as-is.

Set **https://hytiger.github.io** as the website in Play Console (Store settings → contact details),
then use "Check for updates" on the app-ads.txt page in AdMob.
